# Arquetipos Fundamentales del Motor de Prescripción

Este directorio contiene las definiciones de arquitectura fisiológica, reglas de negocio y matrices de decisión para los motores de prescripción autónoma de **Bienestar APP**. 

Cada arquetipo modela las vías metabólicas, gestión de fatiga, prevención de lesiones, requerimientos nutricionales y sustituciones inteligentes (Smart Swaps) específicas de la disciplina.

## Arquetipos Fundamentales (Roadmap de Arranque Robusto)

| # | Arquetipo | Estado | Descripción |
|---|-----------|--------|-------------|
| 1 | **CrossFitter** | ✅ Modelado | Del atleta Scaled al Competitor. Gestión de intereferencia concurrente, WODs, ACWR y fatiga del SNC. |
| 2 | **Runner** | ✅ Modelado | Del 5K al Ultratrail. Zonas de Joe Friel (LTHR), GAP (Grade Adjusted Pace) y picos de sesión única. |
| 3 | **Especialista en Calistenia / Peso Corporal** | ✅ Modelado | Árboles de palanca biomecánica, Torque, SSC (Steady State Cycle) y volumen isométrico. |
| 4 | **Atleta Híbrido** | ✅ Modelado | Combinación de fuerza/estética con resistencia aeróbica. Modulación inversa de volumen y ACWR Dual. |
| 5 | **Deportes de Equipo** | ⏳ Pendiente | Periodización Off-season vs In-season, agilidad, potencia. |
| 6 | **Entusiasta de Yoga / Movilidad** | ⏳ Pendiente | Adaptaciones del tejido conectivo, control motor, flexibilidad. |
